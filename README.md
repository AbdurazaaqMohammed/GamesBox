# GamesBox

An offline party game box for Android. Pass one phone around your group and play 36 pass-and-play games. No accounts, no ads, no internet, and it runs on every Android version.

## Games

| Game | How to play |
| --- | --- |
| Imposter | Everyone gets the same secret word except the imposter, who only sees the category. Give one-word clues, then vote the faker out. 3-10 players, 8 word categories. |
| Would You Rather | 90 tough choices. Each player taps their pick and the tally updates. |
| Never Have I Ever | Everyone starts with 10 fingers. Tap whoever has done it - first to zero loses. |
| Charades | A secret word, a timer, and pure acting. 6 packs. |
| Most Likely To | Read the prompt, point at the likely suspect, and score points. |
| Truth or Dare | 100+ truths and dares. |
| Emoji Movie | Guess the movie from its emoji clue. Score tracking. |
| Stop the Bus | Scattergories-style: a letter plus 3 categories, first one done calls "stop the bus". |
| Hot Potato | A topic appears and everyone says a fitting word, then passes the phone. A hidden random timer ends the round with a buzz - the holder does a challenge. |
| Mad Libs | Fill in the blanks (nouns, verbs, adjectives...) and read the silly finished story out loud. 10 stories. |
| 20 Questions | One player sees a secret word, everyone else asks yes/no questions to guess it in 20. |
| Taboo | Describe the word without saying it or its two banned words. Timed turns with scores. |
| 5 Second Rule | Name 3 things in a category in 5 seconds, then pass the phone. |
| Two Truths and a Lie | Each player states 3 claims, the group votes which is the lie. |
| Story Chain | An opening line appears; each player types a sentence and the group reads the finished story. |
| Word Chain | Say a word starting with the last letter of the previous one; a hidden timer buzzes and the holder does a challenge. |
| Pictionary | Draw on the phone with your finger while your team guesses. Team scores. |
| Simon Says | One command shows for everyone: obey only if it starts with "Simon says". Mark who failed, skip if all behaved; last player standing wins. |
| Scavenger Hunt | A list of things to find appears ("something green", "something that spins") with a timer; teams race to collect them and score. |
| Rhyme Time | Say a word, the next player must rhyme it before a hidden timer buzzes; the holder does a challenge. |
| Higher or Lower | A number shows; guess if the next one is higher or lower. Fast, pass the phone, chain a streak. |
| Bulls and Cows | Think of a number or word; guessers type attempts and get "2 right place / 1 right wrong place" hints. |
| Memory Match | A grid of face-down emoji tiles; tap pairs to match. Fewest flips wins the round. |
| Time Master | The phone shows a target time, then the clock starts - stop it when you THINK the target is up. Closest stop wins. |
| Reaction | The screen stays red, then flips green at a random moment. Tap as fast as you can - tap early and you redo it. |
| Super Recall | A 3x3 grid of emojis flashes a growing pattern; copy it back tap by tap. Who has the best memory? |
| Genre Swap | Draw a movie and a bizarre genre (Jaws as a romantic comedy); pitch it hard, the group judges. |
| Accent Roulette | A random phrase meets a random accent ("the ducks are plotting" as an Italian opera singer); perform it, the group scores. |
| Wavelength | The clue giver peeks at a hidden target on a spectrum and hints the group with one word; lock in your spot and hit the zone. |
| Werewolf | Pass the phone at night: wolves pick a victim, the Seer investigates, the Doctor saves; by day the village votes. Secret roles until the end. |
| Don't Touch the Spikes | The bird flies left and right between two fixed walls studded with 3-5 spikes - tap to flap, and the spikes re-arrange every time you bounce off a wall. The ceiling and floor are lined with spikes, so stay in the middle. A 3-second countdown starts each turn. Best survival time wins. |
| Knife Hit | Tap anywhere to throw a knife into a spinning target. Each knife that lands speeds the wheel up - throw all your blades without hitting one already stuck. Hitting a stuck knife ends your turn. Most knives in wins. |
| Whack-a-Mole | One shared round: each player picks a mole color, then everyone whacks only their color on one big 4x4+ board (decoys score nothing). Most points wins. |
| Darts | Everyone throws three darts at the same board - swipe from the dart at the bottom toward your target. Each player has their own dart color and every dart stays on the board. Highest score wins. |
| Bowling | Swipe on the lane to aim (a short guide shows the ball's line), release to roll - pins fall only when the ball reaches them. Two rolls per player, most pins wins. |

## Features

- Runs on all versions of Android (minSdk 1)
- Tiny - the release APK is ~200 KB
- No permissions except vibration (for a few games like Hot Potato).
